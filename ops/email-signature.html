  1. In Gmail on a computer: gear icon → See all settings → General → Signature → Create new.
  2. Click in the signature box and paste.
  3. Under Signature defaults pick it for new emails and for replies, then Save Changes at the bottom.

If the logo does not come across when you paste: in the signature box click the picture icon, choose Web address (URL), and enter https://yardscout.io/icon-192.png, then set its size to Small.
